# Logic Revision

Today I revised how the CPU executes loops.

Important understanding:

- Outer loop controls rows.
- Inner loop completes all iterations before the outer loop updates.
- The CPU always follows:
  1. Initialization
  2. Condition
  3. Execute
  4. Update
  5. Repeat
